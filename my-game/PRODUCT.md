## Users

## Product Purpose

A Korean-language self-introduction page for 라이언. It exists so the owner can experiment with layout, type, motion and visual styles and see the results immediately in the browser. Success means the page feels like theirs and each experiment is easy to see and change.

- Viewed on the owner's Windows PC in a desktop browser; should still hold up at phone width.
- Content lives in a `const ME = { ... }` object at the top of the page script so it can be edited in one place.
