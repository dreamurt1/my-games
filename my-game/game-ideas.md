# 웹 게임 아이디어 모음 (Claude Code 참고용)

이 문서는 개인 프로젝트 "간단한 캐주얼 웹 게임"의 아이디어를 정리한 것입니다.
아직 만들 게임이 확정되지 않았습니다. 사용자가 고른 게임만 구현하세요.
"미정"으로 표시된 항목은 임의로 정하지 말고 사용자에게 먼저 물어보세요.

---

## 0. 공통 방향 (모든 게임에 적용)

- 참고한 게임: One Shot, Stray
- 닮고 싶은 점: 은은한 분위기의 디자인과 메시지
- 다르게 할 점: 원작의 스토리라인과 구성을 따르지 않고, 미니멀하고 직관적으로 만든다
- 조작: 누구나 할 수 있게 간편하게 (설명 없이 이해되는 것이 목표)
- 분위기 키워드: 빛, 희망, 따스함
- 색상 키워드: 인디고, 주황, 노랑
- 참고 색상값 (스케치에서 쓴 값, 확정 아님)
  - 배경 인디고 `#1B2559` / 더 짙은 인디고 `#121A45` / 어둠 `#0C1233`
  - 주황 `#FF9A3C` / 노랑 `#FFD66B` / 연노랑 `#FFE9A8`
- 연출 원칙: 점수·상태는 숫자보다 화면이 밝아지는 변화로 보여 준다. 게임 오버도 부드럽게 끝낸다.
- 개발 환경: 웹 게임 (HTML + Canvas + JavaScript가 기본 가정), 사용자는 Windows 노트북의 cmd에서 Claude Code를 사용
- 제약: 효과음, 긴 대사, 복잡한 메뉴는 넣지 않는다. 텍스트는 짧은 메시지 한 줄 정도만.

## 1. 불씨 (Little Ember)

- 상태: 스케치(플레이 화면 이미지)까지 제안됨
- 장르: 힐링 원터치 아케이드 (수집형)
- 다른 이름 후보: 온기 한 줌, 밤의 등불
- 한 문장: 작은 불씨를 움직여서 어둠 속에 꺼져 있는 등불을 하나씩 밝히며 세상을 따뜻하게 되살리는 게임
- 조작: 마우스 또는 손가락 하나. 불씨가 포인터를 부드럽게 따라온다.
- 화면 구성
  - 배경은 짙은 인디고. 등불을 켤수록 화면이 따뜻한 노랑빛으로 물든다.
  - 불씨: 주황색, 주변이 은은하게 밝아짐, 지나온 자리에 작은 불티가 남음
  - 등불: 꺼진 것은 어두운 인디고 계열, 켜진 것은 노랑
  - 어둠 안개: 천천히 떠다니며 불씨에 닿으면 온기가 줄어듦
  - HUD: 왼쪽 위에 켠 등불 수(점수), 오른쪽 위에 온기 게이지
  - 첫 플레이 때만 꺼진 등불 주위에 점선 원 힌트를 보여 주는 안을 고려 중
- 점수: 꺼진 등불을 켤 때 +1. 짧은 시간 안에 이어서 켜면 연속 보너스. 켠 등불은 계속 남아 화면이 점점 밝아진다.
- 온기 게이지: 시간이 지나거나 어둠 안개에 닿으면 줄고, 등불을 켜면 채워진다.
- 켜는 방법: 꺼진 등불 가까이에서 불씨가 잠깐 머물면 켜진다.
- 종료: 온기 게이지가 0이 되면 끝. 불씨가 작은 별이 되어 하늘로 올라가는 연출 후 메시지 한 줄(예: "당신이 밝힌 빛 12개, 누군가의 밤이 따뜻해졌어요.")과 "다시 한 번" 버튼.
- 미정: 등불 켜기에 필요한 머무는 시간, 게이지 감소 속도, 등불 배치 방식(무작위/패턴)
- 구현 난이도: 낮음 (Canvas, 포인터 추적, 거리 판정)

---

## 2. 등대지기 고양이

- 상태: 한 줄 제안만 있음 (초안 수준)
- 장르: 퍼즐형 (Stray의 느낌이 강함)
- 한 문장: 고양이를 탭으로 이동시켜 어둠 속 길목마다 등불을 켜는 퍼즐 게임
- 조작: 탭(클릭)으로 고양이 이동
- 점수, 종료 조건, 화면 구성: 미정
- 구현 시 사용자와 먼저 정할 것: 길(격자/자유 이동), 스테이지 구조, 퍼즐 규칙, 클리어 조건

---

## 3. 새벽까지

- 상태: 한 줄 제안만 있음 (초안 수준)
- 장르: 구슬 굴리기형 수집 (One Shot의 '빛을 지키는' 느낌이 강함)
- 한 문장: 해를 닮은 구슬을 굴려 별 조각을 모으며 밤을 건너가는 게임
- 조작, 점수, 종료 조건, 화면 구성: 미정
- 구현 시 사용자와 먼저 정할 것: 조작 방식(마우스/기울기/키), 밤이 끝나는 조건(시간/거리), 실패 조건

---

## 4. 빛의 정원 (Glow Garden)

- 상태: 플레이 화면 스케치는 텍스트 형태로만 제안됨 (이미지 없음)
- 장르: 힐링 가드닝 디펜스 (위에서 내려다보는 방향키 이동형)
- 다른 이름 후보: 등불 정원사, 꽃 피는 밤
- 한 문장: 등불 정원사를 방향키로 움직여 빛의 씨앗을 심어서, 밀려오는 어둠으로부터 정원을 지켜 꽃을 피워 내는 게임
- 조작
  - 방향키(또는 WASD): 정원사 이동
  - 스페이스바: 가진 씨앗 심기
- 화면 구성
  - 배경은 짙은 인디고 땅. 꽃이 피면 그 주변이 따뜻한 노랑으로 물든다.
  - 정원사: 주황색 작은 등불을 든 캐릭터
  - 빛의 씨앗: 화면 곳곳에 별가루처럼 떠오르며, 지나가면 자동으로 주워진다.
  - 어둠: 인디고보다 짙은 안개가 가장자리에서 안쪽으로 천천히 번져 온다.
  - 정원 한가운데에 큰 등불이 있다.
  - HUD: 왼쪽 위에 피운 꽃 수(점수), 오른쪽 위에 정원 등불 상태
- 점수: 심은 씨앗이 꽃으로 피어나는 순간 +1 (심고 약 3초 뒤 개화). 꽃이 서로 가까이 피면 빛이 이어지며 연쇄 보너스. 핀 꽃은 어둠을 밀어내는 빛 영역을 만든다.
- 시듦: 꽃이 시들면 그 자리의 어둠이 다시 번진다. 시간이 갈수록 긴장감이 조금씩 올라간다.
- 종료: 어둠이 정원 한가운데의 큰 등불에 닿으면 끝. 등불이 천천히 잦아들고 남은 꽃들이 마지막으로 반짝인 뒤 메시지 한 줄(예: "어둠이 와도, 당신이 피운 꽃 12송이는 오래 빛났어요.")과 다시 시작 버튼.
- 미정: 격자(타일) 기반으로 할지 자유 이동으로 할지, 씨앗 등장 빈도, 꽃이 시드는 조건, 어둠이 번지는 속도
- 구현 난이도: 중간 (키 입력, 타일/영역 확산 로직)

---

## 구현 순서 제안 (사용자 확정 전까지는 참고만)

1. 사용자가 구현할 게임 하나를 고른다.
2. 1단계 프로토타입: Canvas 설정, 이동/조작, 핵심 상호작용 1개(예: 불씨라면 등불 켜기)까지만.
3. 점수와 종료 조건 추가.
4. 빛 번짐 효과, 종료 연출, 메시지 등 분위기 다듬기.
